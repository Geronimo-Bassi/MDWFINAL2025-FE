# Sistema de Gestión de Tratamientos Médicos

Aplicación web para la gestión de tratamientos médicos, desarrollada como proyecto final para Metodologías de Desarrollo Web 2025. Utiliza Firebase para la autenticación y un backend propio para el manejo de datos.

## Tecnologías principales

- Frontend: React 19, TypeScript, Vite
- Estado: Redux Toolkit
- Routing: React Router DOM
- Estilos: Tailwind CSS, Shadcn UI
- Autenticación: Firebase Auth
- HTTP: Axios
- Formularios: React Hook Form, Joi

## Funcionalidades destacadas

- Registro e inicio de sesión (email/contraseña y cuentas de Google).
- Rutas protegidas para usuarios autenticados.
- CRUD completo de tratamientos médicos, validado en frontend y backend.
- Soporte para baja lógica y física de registros.
- Estado global manejado con Redux.
- Interfaz responsive con notificaciones y modales de confirmación.
